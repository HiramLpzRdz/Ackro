# ServiceCard
Foto de esquinas rectas, categoría en `accent` (14px), título en `card-title` (`ink`) y un ArrowButton alineado a la base del título.

El consumidor da la imagen, la categoría («Diseño residencial») y el título («Fachadas, Jardines e Interiores»). Se usa en rejilla de dos columnas desfasadas sobre `cream`.

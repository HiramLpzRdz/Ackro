# SectionHeading
Antetítulo naranja (`eyebrow`, `accent`) seguido del título en Space Grotesk 44px 700 (`ink-heading`).

El consumidor da ambos textos. El antetítulo nombra la sección con la marca («Clientes de Ackro Habita»); el título es la promesa («Sus Opiniones: Tu mejor Garantía»). Nunca en mayúsculas.

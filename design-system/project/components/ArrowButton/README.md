# ArrowButton
Botón circular de 48px con flecha de 15px, borde 1px `ink` y `radius-round`; abre el detalle de una tarjeta de servicio o de un elemento de lista.

Sobre fondos oscuros usa `.ak-arrow--dark` (borde `umber-700`, flecha `surface`). Siempre lleva `aria-label` con el destino. En el sitio mide 49×51 por un padding asimétrico; aquí es un círculo exacto.
